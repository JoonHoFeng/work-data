# 工作日志管理系统 (Worklog)

个人每日工时 + 工作内容 + 完成事项追踪工具。  
支持**日 / 周 / 月**多维度复盘，一键导出专业 Excel 月报。

## 核心功能

- 📝 **每日快速录入**：一条或多条工作项（描述、时长、分类、完成状态、备注、亮点标记）
- 📊 **今日看板**：实时总工时、目标对比、已完成 / 进行中清单
- 📆 **本周视图**：7 天工时分布 + “本周完成事项”聚合列表 + 达标统计
- 🗓️ **本月视图**：热力图、趋势折线、分类饼图、Top 完成事项
- 📤 **一键月报 Excel**：多 Sheet（明细 + 完成清单 + 统计 + 图表），带公式可编辑
- ⚙️ **自定义设置**：分类管理、每日标准工时（默认 8h）、数据备份

## 快速开始

### 环境要求
- Python 3.9+
- macOS / Linux / Windows 均可（已在内网 Mac 上验证）

### 安装步骤

```bash
# 1. 进入项目目录
cd ~/Desktop/工作日志

# 2. 创建虚拟环境（推荐）
python3 -m venv .venv
source .venv/bin/activate   # macOS/Linux
# .venv\Scripts\activate    # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 初始化数据库 + 种子示例数据（首次必须）
python3 scripts/init_db.py

# 5. 启动应用（推荐）
./run.sh          # 前台启动（自动打开浏览器）
./run.sh bg       # 后台启动（推荐长期运行，不自动开浏览器）

停止后台服务：`./stop.sh`
```

浏览器会自动打开 http://localhost:8501（前台模式）

### 日常使用流程（推荐 < 30 秒/天）

1. 打开 App → 默认停在「今日」页
2. 选择日期（默认今天）
3. 在表单中添加 1~N 条工作项
4. 提交 → 自动刷新今日汇总 + 完成清单
5. 周五/月底 → 切换「本月」页 → 点击「导出本月 Excel 复盘」

### 后台运行
```bash
./run.sh bg          # 后台启动
./stop.sh            # 停止服务
tail -f streamlit.log  # 查看日志
```

## 页面说明

| 标签页 | 主要内容 |
|-------|---------|
| 📅 今日 | 录入表单 + 今日总工时卡片 + 按状态分组列表 |
| 📆 本周 | 周选择器 + 每日柱图 + 本周完成事项汇总 + 总时长/达标天数 |
| 🗓️ 本月 | 月度热力图 + 趋势线 + 分类占比 + Top 亮点事项 + 导出按钮 |

## 数据存储

- SQLite 单文件：`data/worklog.db`（可直接复制备份）
- 所有查询本地运行，**零网络、零上传**
- 建议每月手动备份一次（设置页有按钮）

## 导出的 Excel 月报结构

文件名示例：`工作日志_2026年05月复盘.xlsx`

- **Sheet1 - 每日明细**：日期、总时长、条目数、完成数、亮点数
- **Sheet2 - 完成事项清单**：所有 `done` + `is_highlight` 项，带时长和分类
- **Sheet3 - 统计汇总**：总工时、分类分布表、与 8h 目标对比、Top 3 分类
- **Sheet4 - 图表页**：每日工时柱图 + 分类饼图（Excel 原生图表）

报告使用 Excel 公式（SUM/COUNTIF 等），后续可手动增补内容。

## 分类默认值（可自定义）

开发、会议、测试、联调、文档、学习、其他

## 常见问题

**Q: 端口 8501 被占用怎么办？**  
`streamlit run app.py --server.port 8502`

**Q: 想在终端快速添加一条记录？**  
v1 暂无 CLI（按计划优先 Web）。v2 会提供 `python -m worklog add ...`。

**Q: 数据能和现有「学习心得复盘模板」联动吗？**  
v2 规划中，可从月度完成事项一键生成带「本月工作总结」的复盘 Excel。

**Q: 如何彻底卸载/迁移数据？**  
直接删除整个 `工作日志` 文件夹，或只拷贝 `data/worklog.db` 到新机器。
